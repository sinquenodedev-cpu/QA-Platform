Run all presets

Creates a fresh QA group with one test user per preset and a dashboard login, then checks every report against what the preset should show.

Each check compares the dev API's report with the preset's intended result (adherence, trend, pace, measurements) and with the tool's own recalculation of the rules. Takes about a minute.

Report checker

Recalculates every user's report from their raw measurements and flags anything the dev API shows differently.

The rule check is free and runs in the tool. The AI only writes the summary.
